# User Guide — WorkflowSwift

## Getting Started

1. Go to `https://workflowswift.com/register` to create an account
2. You'll receive an API key automatically — used to authenticate your workflow deployments
3. Credits are granted based on your plan (Free: limited, Paid: monthly allowance)

## Workflows

- **Create**: Build multi-step workflows from templates or from scratch
- **Deploy**: Push workflows to the n8n execution engine with one click
- **Run**: Execute workflows manually or set up triggers (webhook, schedule, dashboard data)
- **Steps**: Each step uses a provider integration (AI, SMS, email, API calls, etc.)

## Credits

- Every workflow execution costs 1 credit
- Failed executions are refunded automatically
- Check your balance: Dashboard → Credits
- Purchase packages or upgrade your plan for more

## Integrations

Connect your own API keys for:
- AI providers (OpenAI, Claude, etc.)
- SMS (Twilio, Telnyx)
- Email (Mailgun, SendGrid)
- Social media, CRM, and more

Go to Settings → Integrations to configure.

## API Access

Generate API keys in Settings → API Keys for programmatic access to your workflows.
