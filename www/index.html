Download the extension (.zip) → Install guide

Manifest V3 · the button always serves the current build, straight from the WorkflowSwift app.

Install in three steps

  1. Download the zip and unpack it into a folder you will keep — Chrome loads the extension from that folder, so don't delete it afterwards.
  2. Open chrome://extensions in Chrome, switch on Developer mode (top-right), click Load unpacked and select that folder (the one holding manifest.json).
  3. In WorkflowSwift, open API Keys, click + New API Key and copy it, then paste it into the extension's Options page and press Test Connection.

Sideload only: Swift Market Intel is not published on the Chrome Web Store, so there is no one-click “Add to Chrome” — Chrome will tell you the extension came from outside the store, and updates are manual (download the current build again and press Reload on chrome://extensions). The extension asks for the 12 marketplace domains below plus activeTab — never “all sites”.
