Privacy Policy

Last Updated: August 6, 2026

1. Information Collected
• Account Information: Name, email address, password hash, and payment details (processed securely via third-party payment processors like Stripe).
• Usage & Telemetry: IP address, browser type, feature usage counts, execution logs, and runtime performance metrics.
• Integration Credentials: API keys, webhook URLs, or tokens supplied by you to run custom workflows. These credentials are encrypted at rest and in transit.

2. How Information Is Used
SwiftSoftware processes collected data to:
• Operate, maintain, and deliver WorkflowSwift features.
• Enforce plan execution limits and manage billing transactions.
• Send transactional notifications, security alerts, and system status updates.

3. Data Sharing & Third Parties
SwiftSoftware does not sell your personal data or workflow logs. Data is shared strictly with essential service providers (e.g., cloud hosting, payment gateways, transactional email services) necessary to operate the application.

4. Data Retention & Deletion
You can request account deletion at any time. Upon deletion, your account information, connected API tokens, and stored workflow definitions will be permanently erased from active production databases within 30 days.
