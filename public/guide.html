WorkflowSwift Guide

Build visual automation pipelines — connect apps, trigger actions, display live dashboards

Dashboard

Command center. Total workflows, active runs, completions, failure rates. Quick actions: create workflow or browse templates.

Workflows

View all workflows. Each shows name, status (active/paused), last run, trigger type. Click to edit. Archive old ones.

1
View List — Status indicators for each workflow
2
Create — Name + trigger type (webhook, schedule, manual)
3
Edit/Delete — Click to edit steps, delete when done

Workflow Builder

Drag-free card-based editor. 11 step types: Webhook, Schedule, Manual Form, HTTP, Email, Condition, Dashboard Widget, Math, Output, File Storage, Custom API.

Dashboard Widgets

Push workflow data to real-time widgets. Cards, tables, or charts. Add a Dashboard Widget step in your workflow.

Run History

Every execution logged: start time, duration, success/failure, step-by-step outputs. Click any run to debug.

Templates

Pre-built workflows: Brand Monitor, Competitor Checker, Lead Finder, Email Alerts. Clone and customize.

Settings

Profile, password, API keys, webhook URLs for incoming triggers.
